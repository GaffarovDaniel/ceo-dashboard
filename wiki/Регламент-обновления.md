# Регламент обновления данных

1. До 5-го числа бухгалтерия выгружает данные за прошлый месяц в CSV.
2. Аналитик загружает файл в `data/raw/kpi_raw.csv` (Add file → Upload files).
3. В сообщении коммита указывается месяц: `Данные за 2026-10`.
4. GitHub Actions автоматически пересобирает отчёт и дашборд (~1 мин).
5. Аналитик проверяет вкладку **Actions** (зелёная галочка) и открывает дашборд.
6. Если сборка упала — создаётся Issue с меткой `bug`.
