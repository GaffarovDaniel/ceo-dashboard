# Словарь KPI

| Показатель | Формула | Зачем CEO |
|---|---|---|
| Выручка | Σ revenue | масштаб бизнеса |
| Выполнение плана, % | revenue / plan_revenue × 100 | дисциплина исполнения бюджета |
| Валовая прибыль | revenue − cogs | эффективность закупок |
| EBITDA | валовая прибыль − opex | операционная прибыльность |
| Маржа EBITDA, % | EBITDA / revenue × 100 | сравнение регионов между собой |
| Средний чек | revenue / orders | ценовая политика, кросс-продажи |
| Отток, % | churned / active × 100 | удержание клиентов |
| NPS | % промоутеров − % критиков | лояльность |
