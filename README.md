# Дашборд для CEO — ООО «Вектор Ритейл»

Учебный сквозной проект по дисциплине «Технологии хранения данных»
(Уральский филиал Финуниверситета). Тема №19: «Составление дашборда для CEO —
ключевые индикаторы бизнеса в реальном времени».

**Автор:** Гаффаров Д. М., группа ЧЛБ25-ИУП-БИ01

## Что внутри

| Папка | Назначение |
|---|---|
| `data/raw/` | сырые выгрузки из учётной системы (не редактируются вручную) |
| `data/processed/` | очищенные данные с рассчитанными KPI |
| `excel/` | первичный анализ в Excel (ПР №4) |
| `scripts/` | скрипты очистки, отчёта и дашборда |
| `docs/` | опубликованные отчёт и дашборд (GitHub Pages) |
| `wiki/` | исходники страниц Wiki |
| `project/` | метрики проектной доски, диаграмма сгорания |
| `.github/workflows/` | автоматизация: сборка отчёта, еженедельный бэкап |

## Ключевые показатели

Выручка и выполнение плана, EBITDA и маржинальность, NPS, отток клиентов,
новые клиенты, средний чек — в разрезе 4 регионов, помесячно.

> Данные модельные (сгенерированы скриптом `scripts/00_generate_demo_data.py`),
> компания вымышленная.
